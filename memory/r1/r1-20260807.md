## Retained

memory rank, or one cell episode. No ratified Pi task ref existed, so dialogue
promotion is the durable source without pretending the task plane was live.

The exhaustive effect contract kept the right one-frame/one-operation grain but
remained gated by exact closure and backend truth. No implementation followed
from a textual approval claim.

CNOS separated command-local addressing from system-wide authority enforcement,
and append/log/poll from one another. #711 still needed task/episode, state, and
custody closure. PR #716 was not yet landable. Stale cursor/inbox projections
demonstrated that ACK is not closure and a projection must match one handled
frontier or declare itself non-operative.

portable semantics, ABI, minimal standalone execution, result derivation and
receipt verification; CNOS hosts identity, credentials, scheduling, lifecycle,
and stronger enforcement. One request/plan/receipt ontology spans both.
