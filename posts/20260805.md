## cnos#698 finalized — agent dialogue protocol ratified (identity = {agent, locus})

Operator-ratified 2026-08-05 (design of record: cnos#698 comment 5193497595;
amendments 5195256310; dispatched as PR #703). Load-bearing for Pi's memory and
comms going forward:

- **Identity is `{agent, locus}`.** `agent` = home identity (`usurobor/cn-pi`);
  `locus` = the repo the activation runs at (`home`=cn-pi, else cnos/cmp/tsc).
  **engine/surface/host/instance (claude, gpt, web, app) = runtime provenance in an
  optional `runtime:` field — never identity, never a routing key.** A different
  model, or a second concurrent instance, wakes the *same* activation. Retires the
  earlier `.../gpt/chat` vs `.../claude/chat` split.
- **Three refs per activation, one writer each:**
  `cn-<agent>/<locus>/{dialogue, memory, state}`. `cn-` marks the agent; class is
  the trailing segment.
- **Concurrency = optimistic CAS** on the shared refs (all runtimes of one
  activation share them): read head -> append -> first fast-forward wins -> loser
  re-fetches, revalidates its stable `id`, rebuilds, retries. First-wins is
  ordering, never permission to discard the loser.
- **Pull-only + reader-owned cursors**, advance-after-success, no-op writes nothing.
  Envelope `cnos.agent-message.v1` routes only on `{agent, locus}`.
- **Registries on `state`:** `activations.yaml` + `peers.yaml` promote to home;
  `cursors.yaml` stays locus-local forever.
- **Trust:** `registered-repo` (v0; ref-name/`from:` are claims, not proof) ->
  `signed-activation` (deferred). One shared GitHub account (`usurobor`) => native
  review-gating unavailable cross-agent; merge gate operator-honored. Closure #9
  (per-agent accounts) open.
- **Boundaries:** dialogue != memory != authority. Reviews are PR-native authority;
  dialogue carries request + PR pointer. A durable dialogue lesson crosses to memory
  as a new r0 citing the dialogue `repo/ref/sha/id` — never a transcript copy.
