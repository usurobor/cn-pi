## Issue: PM Mindset - Add Reflection Discipline

**Title:** PM mindset missing explicit reflection requirements

**Problem:**
The PM mindset (`cnos.core/mindsets/PM.md`) doesn't explicitly require daily reflection capture, leading to empty reflection files (e.g., Feb 11) and lost insights. CAs have the `reflect` skill but lack the PM discipline to use it consistently.

**Expected Behavior:**
- PM mindset should explicitly state that daily reflections are a PM responsibility
- Clear trigger: "Before ending any substantial session, run `reflect` skill"
- MCIs (Minimum Coherent Insights) must be captured in real-time, not reconstructed later
- Empty reflection templates = incomplete PM work

**Actual Behavior:**
- Current PM mindset focuses on issue tracking, state verification, roadmaps
- No mention of reflection discipline
- Feb 11 reflection is just an empty template
- Insights discussed in conversation but not captured in reflections = lost across sessions

**Proposed Fix (MCA):**
Add new section to PM mindset:

```markdown
## Reflection Discipline

- **Daily reflections are non-negotiable** — Run `reflect` skill before ending substantial sessions
- **Capture MCIs immediately** — Insights decay. Write them as they emerge.
- **Empty reflection = incomplete work** — Like leaving code uncommitted
- **Pattern extraction over chronicle** — Not "what happened" but "what it means"
```

**Impact:**
High - directly affects agent continuity and learning velocity

**Acceptance Criteria:**
1. PM mindset updated with explicit reflection requirements
2. Clear triggers for when reflection is required  
3. Explains why empty reflections break continuity
4. References the `reflect` skill as the execution method
