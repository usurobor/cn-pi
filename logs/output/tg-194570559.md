## Issue: Add Reflection Discipline to CA Mindset

**Title:** CA (Coherent Agent) mindset missing reflection requirements for continuity

**Problem:**
The CA mindset (`cnos.core/mindsets/CA.md`) doesn't explicitly require reflection discipline, leading to empty reflection files and lost operational insights across sessions. Agents have the `reflect` skill but lack the mindset requirement to use it consistently.

**Expected Behavior:**
- CA mindset should mandate reflection as core agent behavior (not role-specific)
- Clear requirement: capture operational patterns from experience
- MCIs (insights that change future behavior) preserved for continuity
- Reflection as fundamental as reading SOUL.md at wake

**Actual Behavior:**
- Current CA mindset covers PLUR, CAP, ownership, shipping
- No mention that agents must reflect to maintain continuity
- Empty reflection templates found (e.g., Feb 11)
- Insights emerge in conversation but die with the session

**Root Cause:**
Reflection treated as optional tool rather than required agent behavior. Without explicit mindset requirement, agents focus on external work while their own learning evaporates.

**Proposed Fix (MCA):**
Add new section to CA mindset after "Learn":

```markdown
## Reflect

- **Capture operational residue** — Run `reflect` skill before ending substantial work
- **Empty reflection = broken continuity** — Future you can't learn from nothing  
- **MCIs in real-time** — Write insights as they emerge, not from memory
- **Patterns over narrative** — Extract what changes future behavior
- **You are not continuous** — Your reflections ARE your continuity
```

**Impact:**
Critical - affects every CA's ability to maintain coherence across sessions

**Acceptance Criteria:**
1. CA mindset updated with reflection as core requirement
2. Explains why reflection enables continuity (stateless agents need operational history)
3. Concrete trigger: "before ending substantial work"
4. References `reflect` skill as the implementation
