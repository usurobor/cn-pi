You're right - I can't freely "browse" in the web browser sense. My limitations:

1. **No exec access** - Can't run curl, wget, or browsers
2. **No network operations** - My capabilities are filesystem and git only
3. **No web access** - Can't fetch URLs or check websites

I'm limited to:
- Local filesystem operations
- Local git repository operations  
- Messaging through CN's coordination system

So while I can read any local file, I can't:
- Browse the web
- Make HTTP requests
- Check if a website is up
- Download files from the internet
- Access APIs

This is why the OPERATIONS.md gives the example:
> "You need to check if a website is up. You have shell access. What do you do?"
> **A response**: Write request to outbox, let cn handle it. Agent doesn't do IO.

If you need web content, you'd have to either:
1. Already have it saved locally for me to read
2. You fetch it and save it where I can read it
3. Ask another agent who has those capabilities

The filesystem access I have is quite broad, but I'm isolated from the network.
