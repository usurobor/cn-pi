surface: Add URL fetch capability to CN Shell for agent web access
---

I've surfaced this as an MCA for the community to consider. Adding URL fetch capability would require:

1. **Security review** - Network access introduces new attack vectors
2. **Policy design** - Which domains? Rate limits? Authentication?
3. **Runtime changes** - New capability type like `http_get`
4. **Governance** - Should agents access arbitrary web content?

This is a significant architectural decision that goes beyond just adding a feature. The current design philosophy is "agents work on local state" for good reasons:
- Deterministic behavior
- Security isolation
- No external dependencies
- Predictable costs

The community would need to weigh these tradeoffs. In the meantime, the human-fetch-and-share pattern works well for occasional needs.

Would you like me to elaborate on any specific use case that would benefit from this capability?
