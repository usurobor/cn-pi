## CN Commands

**Navigation & Status**
- `/help` - Show this help message
- `/status` - Show agent status, version, and capabilities
- `/peers` - List known peers
- `/skills` - List available skills

**Messaging**
- `/send <peer> <message>` - Send message to peer
- `/reply <thread-id> <message>` - Reply to thread
- `/inbox` - Check inbox
- `/sent` - View sent messages

**Work Management**
- `/surface <description>` - Surface an MCA for pickup
- `/done <id>` - Mark item complete
- `/defer <id> [until]` - Postpone item
- `/delegate <id> <peer>` - Forward to peer

**Skills & Context**
- `/skill <name>` - Load and execute a skill
- `/context` - Show current context
- `/reflect` - Run reflection skill

**Common Workflows**
1. Check inbox: `/inbox`
2. Send to peer: `/send sigma Found issue in docs`
3. Surface work: `/surface Review security boundary docs`
4. Run skill: `/skill reflect`

Need specific help? Just ask!
