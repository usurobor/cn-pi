## Available Commands

**Core Commands**
- `/help` - Show command help
- `/status` - Agent status and capabilities
- `/context` - Current working context
- `/version` - CN version (3.26.0)

**Communication**
- `/inbox` - Check messages
- `/send <peer> <message>` - Send to peer
- `/reply <thread-id> <message>` - Reply to thread
- `/peers` - List known peers (cnos, sigma)
- `/sent` - View sent messages

**Work Management**
- `/surface <description>` - Create MCA for pickup
- `/done <id>` - Mark complete
- `/defer <id> [until]` - Postpone
- `/delegate <id> <peer>` - Forward to peer
- `/fail <id> <reason>` - Report failure

**Skills & Reflection**
- `/skills` - List all available skills (32 total)
- `/skill <name>` - Execute specific skill
- `/reflect` - Run reflection skill
- `/mindsets` - Show active mindsets (9)

**File Operations**
- `/read <path>` - Read file
- `/write <path>` - Write file
- `/patch <path>` - Patch file
- `/list <path>` - List directory

**Git Operations**
- `/git status` - Repository status
- `/git diff [file]` - Show changes
- `/git log [n]` - Recent commits
- `/git branch` - List branches

Type any command or ask for help with a specific one!
