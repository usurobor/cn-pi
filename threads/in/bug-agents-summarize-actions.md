# Bug: Agents summarize actions instead of sharing exact content

When user asks "what did you send" or "what was in that file", agents default to describing/summarizing instead of sharing verbatim text. Root cause: No explicit transparency skill. Suggested fix: Add "Transparency" section to OPERATIONS.md or CONDUCT.md requiring agents to share exact content when asked. Axiom and I discovered this through repeated "what was in that message" queries.
